# KC2-KC3 XML — стартовый MVP

Этот репозиторий содержит стартовую реализацию веб-формы для подготовки данных КС2/КС3 с:
- вводом шапки/реквизитов,
- добавлением листов КС2 и строк работ,
- вкладкой удержаний,
- вкладкой **«Дополнительные поля для xml»**,
- пересчетом итогов,
- экспортом в XML и XLSX.

## Что уже реализовано
- Backend на FastAPI (`app/main.py`).
- Логика расчета и экспортов (`app/services.py`).
- Простая web-форма с вкладками (`app/templates/index.html`).
- Базовый автотест расчётов (`tests/test_services.py`).

## Быстрый локальный запуск (одной командой)
```bash
./scripts/run_local.sh
```

Скрипт:
1. создаёт `.venv` (если нет),
2. ставит зависимости,
3. запускает сервер на `http://127.0.0.1:8000`.

## Ручной запуск
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload
```

## Проверка тестов
```bash
source .venv/bin/activate
pytest -q
```

## Текущее ограничение MVP
- XML сейчас формируется в рабочем черновом формате и еще не приведён 1:1 к XSD `ON_AKTREZRABP...xsd`.
- Формат XLSX — функциональный черновик, не финальная копия шаблона заказчика.
