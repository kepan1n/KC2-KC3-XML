# KC2-KC3-XML — веб-форма (этап 1)

Первый этап реализации:

- веб-форма по структуре Excel `nalog docs/пример заполнения.xlsx`
- общие реквизиты и шапка документа
- отдельные листы КС-2
- автоматический расчёт сумм по строкам и итогов по листу
- сводная вкладка КС-3
- вкладка `Удержания`
- вкладка `Дополнительные поля для XML`
- предзагрузка демо-данных из Excel-шаблона
- локальное сохранение в браузере и экспорт JSON

## Запуск

```bash
./scripts/run_local.sh
```

По умолчанию поднимется статический сервер на <http://127.0.0.1:4173>.

## Файлы

- `index.html` — SPA интерфейс
- `app.js` — логика формы и расчётов
- `styles.css` — стили
- `data/sample-data.json` — демо-данные, извлечённые из Excel-примера
