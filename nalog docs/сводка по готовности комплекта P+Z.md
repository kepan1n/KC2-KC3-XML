# Сводка по готовности комплекта P+Z

Текущее рабочее состояние на small sample.

## Что уже готово

### 1. Файл подрядчика (`ON_AKTREZRABP`)
Генератор: `scripts/generate_xml_from_export.py`

Статус:
- production-full XML реализован
- XSD-valid
- файл `output/small-sample-full.xml` прошёл внешнюю проверку в Контуре без замечаний

Что уже поддерживается:
- полная табличная часть КС-2 (`Раздел` + `СвВидРаб`)
- суммы разделов и строк
- реквизиты шапки подрядческого файла
- `СвОРасч` и удержания
- `ДокПодтСумУд`
- richer `ПодписантПодр`
- OKПО и адрес подрядчика
- `ОснСдачи`
- `ИдСмет`

### 2. Файл заказчика (`ON_AKTREZRABZ`)
Генератор: `scripts/generate_customer_xml_from_export.py`

Статус:
- базовый генератор реализован
- XSD-valid
- файл `output/small-sample-customer.xml` проходит XSD по `ON_AKTREZRABZ.xsd`

Что уже поддерживается:
- `ОснДоверОргСост`
- `ИдИнфПодр`
- `СодФХЖ4`
- `ПодписантЗак`
- привязка к уже сгенерированному подрядческому файлу (`P`)

## Что это значит

На small sample уже собран и проверен рабочий комплект из двух XML-файлов:

1. `P` — подрядчик / КС-2-профиль
2. `Z` — заказчик / КС-3-профиль

## Что ещё не сделано

Это ещё не финальная полировка комплекта. Пока не сделаны:
- экспорт `P` и `Z` прямо из UI двумя кнопками;
- финальная внешняя проверка `Z` в Контуре;
- масштабирование этой же логики на большой исходный Excel с несколькими КС-2.
