## Что это значит практично

- Эти данные есть в исходном Excel, но не входят в строгий «безусловно обязательный» набор 1110335.
- Их можно передавать через **optional-поля XSD** (или через `ДопПолеСтрИнф` / `ИнфПолФХЖ*`).
- Для обмена с ФНС это не ломает XSD, если соблюдена структура и ограничения choice/sequence.
