# Сводная таблица: compact sample vs `sample_1110335.xml`

Цель: держать компактный рабочий кейс (`small sample.xlsx`) максимально близко к минимальному проходному `sample_1110335.xml`, но не терять бизнес-данные формы.

Источники:
- `small test sample/small sample.xlsx`
- `nalog docs/sample_1110335.xml`
- `nalog docs/nalog target.docx`
- `nalog docs/обязательные поля из nalog target.md`

## Текущий статус

- compact sample загружается как основной demo-образец;
- XML по compact sample проходит локальную XSD-валидацию (`output/small-sample.xml = VALID`);
- включён pass-friendly compact профиль для `НаимИСт` и `СвОРасч`;
- дальше работа идёт уже не над «большим» примером, а только над compact sample.

## Что уже можно считать почти готовым для compact Diadoc-friendly профиля

1. Компактный пример стабилен и контролируем.
2. XML для compact sample проходит XSD.
3. Минимальный pass-profile теперь ближе к `sample_1110335.xml` по:
   - `НаимИСт`
   - `СвОРасч`
   - `ПодписантПодр`
   - `СвЗак`
   - `ИнфПолФХЖ1`
4. Критичные XML-поля уже выведены в форму.
