# Карта полей формы -> XML узел

Цель: зафиксировать, куда именно должны попадать данные из веб-формы в production XML 1110335, исходя из текущих решений.

Статусы:
- **уже передаётся** — есть в генераторе
- **нужно внедрить** — решение принято, но ещё не встроено
- **уточнить по формату** — нужен аккуратный выбор допустимого XML-узла

## 9. Практический вывод

Текущий генератор уже покрывает основную production-табличную часть и базовые реквизиты.

Оставшийся обязательный хвост внедрения — это в первую очередь:
1. richer `ПодписантПодр` (`Должн`, `СтатПодп`, `ТипПодпис`)
2. подписи заказчика / техзаказчика в допустимых XML-блоках
3. OKПО участников
4. реквизиты подрядчика по адресу (`индекс`, `регион`)
5. оставшиеся значимые реквизиты шапки формы, если для них найдётся корректный XML-узел по `docx`
